### 🎯 What is SILAS?

**SILAS** is a personal AI agent I'm currently building to go beyond the typical
stateless chatbot.

Instead of treating every conversation as completely new, SILAS is designed to
maintain **context, memory and task history** so it can become more useful over time.

### 🧩 Core Ideas

| Capability | Description |
|---|---|
| 🧠 Long-Term Memory | Store and retrieve useful information from previous interactions |
| 🔎 Context Retrieval | Retrieve relevant information before generating a response |
| 📋 Task History | Keep track of tasks, actions and previous workflows |
| 🔁 Recurring Workflows | Handle repeated tasks and workflows |
| 🤖 LLM Integration | Work with local and cloud-based language models |
| ⚡ Prompt Pipelines | Structure complex tasks into multiple processing steps |
| 🧩 Context-Aware Responses | Generate responses using relevant previous context |
